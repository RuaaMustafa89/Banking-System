This program is a simple banking system  that uses classes and objects. It creates a customer account  and displays the customer's account information and current balance.
The program allows the customer to deposit and withdraw money. It also checks whether the customer has enough money in their account before allowing a withdrawal.
The Classes used are Account (stores the account number and balance), Customer (stores the customer's name and account information) and Transaction (processes deposits and withdrawals).
This makes the code organised and easier to understand. The classes can be reused to create more customers, accounts, and transactions.
Simple names and comments are used to make the code easier to understand.
The program was tested with a starting balance of $500, a $200 deposit , and a $400 withdrawal. The final balance was $300.
